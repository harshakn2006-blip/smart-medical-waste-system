About Project

Smart Medical Waste Management System

MedWaste Smart is a smart web-based medical waste management application designed to improve biomedical waste segregation, identification, collection, tracking and monitoring in healthcare facilities.

The system combines rule-based classification, AI-powered image identification and digital tracking to make medical waste management more organized and efficient.

Project Objectives

  • Improve biomedical waste segregation.
  • Assist staff with AI-based waste classification.
  • Identify visible medical waste items using uploaded images.
  • Maintain a history of AI image identification results.
  • Track waste records using QR codes.
  • Manage waste collection efficiently.
  • Generate reports and analytics.
  • Improve monitoring through role-based access.

Key Features

  • AI Waste Classification: Provides classification suggestions for medical waste items.
  • AI Image Identification: Uses Gemini AI to identify visible medical waste items from uploaded images.
  • AI Identification History: Automatically stores previous image identification results for future reference.
  • QR Code Tracking: Generates QR codes to track individual waste records.
  • Waste Collection Management: Allows staff to create collection requests and collectors to manage collection activities.
  • Analytics Dashboard: Displays waste statistics, collection status, department details and identification history.
  • PDF and Excel Reports: Generates downloadable reports for waste records and management activities.
  • Role-Based Login: Provides separate access for staff, collectors and administrators.

Technologies Used

  • Python
  • Flask Framework
  • HTML, CSS and JavaScript
  • SQLite Database
  • Google Gemini AI API
  • QR Code Generation
  • ReportLab for PDF Reports
  • OpenPyXL for Excel Reports

Safety and Reliability

AI image identification provides suggestions based on the visible appearance of an item. It cannot determine whether an item is contaminated or infectious. All biomedical waste segregation decisions must be verified by trained staff according to applicable biomedical waste regulations and facility procedures.
