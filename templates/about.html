About Project

Smart Medical Waste Management System

The Smart Medical Waste Management System is a web-based application designed to improve biomedical waste management in healthcare facilities.

Project Objectives

  • Improve biomedical waste segregation.
  • Assist with AI-based waste classification.
  • Track waste using QR codes.
  • Manage waste collection efficiently.
  • Generate reports and analytics.

Key Features

  • AI Waste Classification
  • QR Code Tracking
  • Waste Collection Management
  • Analytics Dashboard
  • PDF and Excel Reports
