About MedWaste Smart

MedWaste Smart is a web-based biomedical waste management system that helps healthcare facilities classify, identify, track and manage medical waste efficiently using AI and digital technology.

Project Objectives

  • Improve biomedical waste segregation.
  • Support AI-based waste identification.
  • Track waste records using QR codes.
  • Manage collection activities.
  • Monitor performance through analytics and reports.

Key Features

  • AI Classification: Suggests suitable waste categories.
  • Image Identification: Uses Gemini AI to identify visible waste items.
  • QR Tracking: Tracks individual waste records.
  • Collection Management: Organizes pickup requests and collection status.
  • Analytics: Displays waste statistics and trends.
  • Reports: Generates PDF and Excel reports.
  • Role-Based Access: Supports staff, collectors and administrators.

Technology Stack

Python · Flask · PostgreSQL · HTML · CSS · JavaScript · Google Gemini AI · QR Code · ReportLab · OpenPyXL

Safety Note

AI results are suggestions based on visible appearance. They cannot confirm contamination or infection. Final segregation must be verified by trained staff according to applicable biomedical waste regulations and facility SOPs.
